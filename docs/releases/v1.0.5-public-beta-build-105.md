## What this release is

Build 105 is the first build in the **Public Beta** label (earlier 1.0.x builds
were Pre-Beta). It ships two features that were already merged to `main`, and
renames the whole version line from Pre-Beta to Public Beta.

## Highlights for users

- **Adult-only library metadata (full edition).** The full edition now looks up
  library metadata from adult providers only — ThePornDB and StashDB, with the
  Porn Site Nuxt / IAFD / PhoenixAdult / PGMA fallbacks. The general providers
  (TMDB, OMDb, Cinemeta, TVMaze) are never called, and first-run setup only asks
  for the adult provider keys. The Microsoft Store edition keeps the regular
  providers.
- **Free AI poster vision.** After each scan, a bundled offline CLIP model reads
  every poster to fill empty genre and year fields (it never overwrites values
  you already have). With a Hugging Face token, a stronger model (Qwen3-VL) reads
  printed titles and years. The holo agent can describe an attached image with
  no Anthropic key.

## Bug fixes

- Content ratings are kept on a forced metadata refresh, and the metadata source
  text was corrected.

## Breaking changes and migration

- **Label change: Pre-Beta → Public Beta.** The version line is now "Public
  Beta"; the release tag is `v1.0.5-public-beta`.
- **Metadata provider change (full edition).** Because the full edition now uses
  adult providers only, first-run setup asks for those keys rather than general
  ones. The Store edition is unchanged.
- **Supported-build status.** Build 105 is the supported build; Build 104 is no
  longer listed as supported.

## Known issues and limitations

- At the time of writing, the published GitHub release for
  `v1.0.5-public-beta` had not yet appeared; the release workflow runs on merge.
- The stronger poster-reading model requires a Hugging Face token; without one,
  the bundled offline model is used.
- **Installers are not code-signed** (signing not yet configured), so Windows
  SmartScreen may warn on first run.
- Windows is the only packaged desktop platform for this build.
