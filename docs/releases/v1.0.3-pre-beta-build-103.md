# v1.0.3 Pre-Beta — Build 103

- **Version:** 1.0.3 Pre-Beta
- **Build:** 103
- **Released:** 2026-10-11 (Windows)
- **Platform:** Windows (MSI and NSIS/EXE installers)
- **Previous milestone:** [v1.0.2 Pre-Beta — Build 102](v1.0.2-pre-beta-build-102.md)

## What this release is

Build 103 gives the AI agent an optional photo face: instead of the abstract
hologram head, you can have the agent wear an animated photo of yourself.

## Highlights for users

- **Give the agent your face.** In agent settings, under "Agent face", pick a
  photo and drag three markers onto the eyes and mouth. From then on the agent's
  head is your photo. It blinks, turns slightly with parallax, raises its brows
  while listening, narrows its eyes and looks up while thinking, frowns on
  errors, and moves its jaw in time with the typed answer. A light hologram pass
  (mood tint, scanlines, faded background) keeps it in the panel's style.
- **It all runs on your device.** The photo face needs no account, no cost and
  no network. The photo is never bundled with the app; it is scaled down,
  re-encoded (which strips location/EXIF data) and stored locally.
- **Easy to undo.** Removing the photo brings the hologram head back.

## Bug fixes

- None specific to this build; it is a feature release on top of Build 102.

## Breaking changes and migration

- None. The hologram head remains the default until you choose a photo.

## Known issues and limitations

- The photo face is a stylized, animated still built from one photo — it is not
  real talking-head video.
- **Installers are not code-signed** (signing not yet configured), so Windows
  SmartScreen may warn on first run.
- Windows is the only packaged platform for this build.
