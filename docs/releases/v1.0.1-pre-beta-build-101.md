# v1.0.1 Pre-Beta — Build 101

- **Version:** 1.0.1 Pre-Beta
- **Build:** 101
- **Released:** 2026-10-10 (Windows)
- **Platform:** Windows (MSI and NSIS/EXE installers)
- **Previous milestone:** none — this is the first build of the 1.0.x line

## What this release is

Build 101 is the foundation of the current CinaVault Premium. It resets the
project onto one clean, buildable codebase after a period where the Rust backend
would not compile and the Microsoft Store edition lived in a separate, older
fork. Everything that follows (Builds 102–105) is built on top of this base.

For most users this is a first install rather than an upgrade: the version
numbering restarts at 1.0.x.

## Highlights for users

- **The full library experience, free.** The unified library, first-run key
  setup, offline poster identification and the holographic agent panel are all
  present, and the previous CinaVault Plus paywall has been removed, so every
  feature is free.
- **Controls that now work end to end.** The scan progress bar shows real file
  counts and has a Cancel button; the player picker lists the players installed
  on your PC and remembers your choice; and the Advanced tab has a Duplicate
  Finder that moves extra copies to quarantine instead of deleting them.
- **Planned features are labelled.** Switches that had nothing behind them are
  now disabled and marked "Planned", so the settings reflect what actually does
  something.
- **A Microsoft Store–safe edition from the same code.** A separate build
  (`build:ms-v1`) produces a store-safe edition with every adult surface
  compiled out, built from the same source as the full Premium edition.

## Bug fixes

- The Rust backend compiles again (duplicate-report callers and app icon format
  were fixed).
- The scan progress bar no longer sits at 0 / 0.
- Choosing VLC or MPV as the default player now launches that player instead of
  the system default.
- MediaInfo and MKVToolNix download actions were repaired.
- Media requests now survive an app restart.

## Breaking changes and migration

- **Version reset.** The app moves from the older v2 build numbering to the
  1.0.x line. Treat Build 101 as a fresh install baseline.
- **Paywall removed.** The CinaVault Plus entitlement system, feature gates,
  Account & Plan tab and license tooling were removed. There is nothing to
  purchase or unlock; all features are available to everyone.

## Known issues and limitations

- **Installers are not code-signed.** Signing is not yet configured, so Windows
  SmartScreen may warn on first run. Azure Artifact Signing is wired into the
  release workflow and turns on once the signing account and settings in
  [CODE_SIGNING.md](../CODE_SIGNING.md) are in place.
- Windows is the only packaged platform for this build.
