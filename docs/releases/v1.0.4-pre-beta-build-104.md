# v1.0.4 Pre-Beta — Build 104

- **Version:** 1.0.4 Pre-Beta
- **Build:** 104
- **Released:** 2026-10-11 (Windows)
- **Platform:** Windows (MSI and NSIS/EXE installers)
- **Previous milestone:** [v1.0.3 Pre-Beta — Build 103](v1.0.3-pre-beta-build-103.md)

## What this release is

Build 104 brings the AI agent to the phone apps and fixes several Windows
scanning and metadata problems.

## Highlights for users

- **The agent on your phone.** A signed-in Android or iOS app can now chat with
  the agent through your CinaVault server and show the same agent face as the
  desktop. From a phone the agent is read-only: it can search, give an overview
  and describe an item, but it can't play, rename, refresh or reorganise
  anything, and it can't view posters. Phone answers obey the server's library
  filter, and item details sent to phones leave out the file name.
- **You stay in control of cost and access.** Every phone message spends the
  desktop owner's API credit, so each account is limited to one message at a
  time and 40 messages an hour. The owner can turn the phone agent off, and the
  API key never leaves the desktop.
- **Keep the agent face you set.** The photo face you marked is now kept
  reliably.

## Bug fixes (Windows)

- Metadata provider keys are kept instead of being lost.
- Titles that failed to save are retried instead of silently dropped.
- Posters are saved locally so they survive.

## Breaking changes and migration

- None for the desktop app. The phone agent is new and off until the owner has
  an agent set up and leaves phone access enabled.

## Known issues and limitations

- The phone agent needs a desktop with the agent configured (an Anthropic API
  key) and the phone signed in to the same server.
- **Installers are not code-signed** (signing not yet configured), so Windows
  SmartScreen may warn on first run.
- Windows is the only packaged desktop platform for this build.
