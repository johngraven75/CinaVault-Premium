# v1.0.2 Pre-Beta — Build 102

- **Version:** 1.0.2 Pre-Beta
- **Build:** 102
- **Released:** 2026-10-10 (Windows)
- **Platform:** Windows (MSI and NSIS/EXE installers)
- **Previous milestone:** [v1.0.1 Pre-Beta — Build 101](v1.0.1-pre-beta-build-101.md)

## What this release is

Build 102 turns the holographic agent panel into a real assistant and fixes a
startup freeze that affected Windows users with the MediaInfo desktop program
installed.

## Highlights for users

- **The holo agent becomes Claude.** With an Anthropic API key added in agent
  settings, the panel can hold a conversation, search your library and read item
  details, look at posters and at images you attach or paste, and run the
  source, provider and network diagnostics for you. It offers buttons for
  anything that changes something — play, refresh metadata, fix a title, mark
  watched, find and add media folders, and library tasks like scan, enrich,
  posters, NFO, duplicates, normalize and tags. **Nothing changes until you
  press the button.** Without a key, the panel keeps working exactly as before
  and shows a one-line prompt to add one. Your key stays on the desktop and
  never reaches the web view.

## Bug fixes

- **MediaInfo no longer freezes the app.** On Windows, launching CinaVault could
  open the MediaInfo desktop program and leave the app unresponsive until that
  window was closed. MediaInfo now runs hidden in the background with a time
  limit, and the app window opens without waiting for media-tool setup. A stuck
  tool is stopped instead of hanging the app, and a missing tool shows a clear
  "not installed, use Recheck & Repair" message.
- The Automated Daily Maintenance workflow was repaired.

## Breaking changes and migration

- None. Existing settings and data carry forward from Build 101.

## Known issues and limitations

- **The holo agent's full abilities need an Anthropic API key.** Without a key,
  it falls back to the previous keyword-and-diagnostics assistant.
- **Installers are not code-signed** (signing not yet configured), so Windows
  SmartScreen may warn on first run.
- Windows is the only packaged platform for this build.
